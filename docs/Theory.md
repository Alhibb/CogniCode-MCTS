# Theory of CogniCode-MCTS: Formal Framework

This document provides the mathematical foundation for the **CogniCode-MCTS** system, framing code generation as a discrete state-space search problem guided by heuristic evaluation.

---

## 1. Mathematical Formulation

We define code generation as a Markov Decision Process (MDP) tuple $(\mathcal{S}, \mathcal{A}, \mathcal{T}, \mathcal{R})$:

-   **State Space ($\mathcal{S}$):** The set of all syntactically valid (or potentially valid) code prefixes. A state $s \in \mathcal{S}$ is a string of tokens.
-   **Action Space ($\mathcal{A}$):** The set of possible "next-step" snippets generated by the Large Language Model (LLM).
-   **Transition Function ($\mathcal{T}$):** Deterministic concatenation where $s_{t+1} = s_t \oplus a_t$.
-   **Reward Function ($\mathcal{R}$):** A sparse signal determined by the Code Sandbox:
    $$
    R(s) = 
    \begin{cases} 
    1.0 & \text{if } s \text{ passes all unit tests} \\
    0.1 & \text{if } s \text{ is syntactically valid but incomplete} \\
    -1.0 & \text{if } s \text{ contains syntax errors} \\
    -0.5 & \text{if execution times out}
    \end{cases}
    $$

---

## 2. Selection Heuristic: PUCT

To balance exploration and exploitation, we transition from standard UCB1 to **PUCT (Predictor + UCB for Trees)**, which incorporates a prior probability from the LLM.

The selection of action $a$ from state $s$ is governed by:
$$
a^* = \arg\max_{a \in \mathcal{A}} \left( Q(s, a) + C_{puct} \cdot P(s, a) \cdot \frac{\sqrt{N(s)}}{1 + N(s, a)} \right)
$$

Where:
-   $Q(s, a)$: The mean action value (cumulative reward / visits).
-   $P(s, a)$: Prior probability of action $a$ (provided by the LLM's log-probabilities or heuristic ranking).
-   $N(s)$: Total visit count of the parent node.
-   $N(s, a)$: Visit count of the specific child node.
-   $C_{puct}$: A hyperparameter controlling the weight of the prior vs. exploration.

---

## 3. Value Function Approximation (Neural-Heuristic)

In traditional MCTS, the value of a leaf node is estimated via random rollouts. In **Neural-MCTS**, we replace this with a **Value Head** $V_\theta(s)$:

$$
V(s) \approx \mathbb{E}[R | s] \in [0, 1]
$$

During the Simulation phase, the LLM is prompted to perform a "Heuristic Evaluation" of the state $s$, predicting the conditional probability that a solution exists in the subtree rooted at $s$.

---

## 4. Complexity & Convergence

### Search Complexity
Given a tree of depth $D$ and branching factor $B$, the space complexity is $O(B \cdot D)$. However, through **Value-Based Pruning** and **Progressive Widening**, we constrain the search to the most promising $\epsilon$-neighborhood of the optimal path.

### Convergence
In a finite state space with deterministic rewards, MCTS is guaranteed to converge to the optimal solution as $N \to \infty$. In our context, convergence is defined as reaching a state $s$ where $R(s) = 1.0$.
